# 🇸🇦 SAUDI EXPLORER AI | المنصة السياحية الوطنية الذكية الموحدة للمملكة العربية السعودية

> **Production Ready MVP (النسخة النهائية الاحترافية)**  
> تم تصميم وبناء هذه المنصة لتكون المنصة الوطنية الموحدة المعززة بالذكاء الاصطناعي لخدمة كافة أطراف المنظومة السياحية في المملكة العربية السعودية ضمن أهداف **رؤية السعودية 2030**.

---

## 📌 نبذة عن المنصة (Project Concept & Goals)

تُعد **SAUDI EXPLORER AI** منصة رقمية سياحية متكاملة تربط بين **السياح، المواطنين، المستثمرين، المنشآت السياحية، المرشدين السياحيين، مزودي الخدمات اللوجستية، ووزارة السياحة** في بيئة رقمية ذكية واحدة موحدة.

### 🎯 الأهداف الاستراتيجية:
1. **تمكين التخطيط الذكي للرحلات**: باستخدام نماذج الذكاء الاصطناعي التوليدي والتعلم الآلي لتقديم مسارات سياحية مخصصة بدقة.
2. **التحول الرقمي الشامل للمنظومة**: توفير بوابات مخصصة لكافة أصحاب المصلحة (8 بوابات متخصصة).
3. **التنقل الذكي (Explorer Ride)**: حجز وإدارة أسطول المركبات الفاخرة والكهربائية المباشرة إلى المعالم السياحية مع وضع التوجيه الصوتي السياحي (AI Tour Mode).
4. **التجربة الرقمية التفاعلية**: دعم تقنيات المعالم ثلاثية الأبعاد (3D Models)، الواقع المعزز (AR)، والمرشد الصوتي التفاعلي.
5. **شكر وتكريم زوار المملكة**: نظام الجواز السياحي الرقمي (Digital Saudi Passport) ونظام النقاط والمكافآت والوسامات.

---

## 🏛️ البوابات الثمانية الموحدة (8 Integrated Portals)

1. **بوابة السائح (Tourist Portal)**: استكشاف المدن والمعالم، التخطيط بالذكاء الاصطناعي، حجز الفنادق والتنقلات، والمحفظة الرقمية.
2. **بوابة المواطن (Citizen Portal)**: إضافة تجارب محلية، استضافة السياح، والمشاركة في التنشيط السياحي للحي والمدينة.
3. **بوابة المستثمر (Investor Portal)**: استكشاف الفرص الاستثمارية الكبرى في قطاع السياحة، تحليل العائد المالي، والتقديم على الرخص الموحدة.
4. **بوابة المرشد السياحي (Tour Guide Portal)**: إدارة الجولات السياحية، أوقات التوفر، الحجوزات المباشرة، وتقييمات السياح.
5. **بوابة المنشآت السياحية (Establishments Portal)**: إدارة الفنادق، المطاعم، المقاهي، معايير الجودة، والامتثال للوائح وزارة السياحة.
6. **بوابة مزودي الخدمات (Service Providers Portal)**: شركات النقل، تأجير السيارات، تنظيم الفعاليات، وخدمات الدعم اللوجستي.
7. **بوابة وزارة السياحة (Ministry of Tourism Portal)**: متابعة المؤشرات الوطنية (KPIs)، تصاريح الجودة، الخرائط الحرارية لكثافة السياح، والرقابة الذكية.
8. **بوابة مدير النظام الأعلى (Super Admin Portal)**: إدارة المستخدمين والصلاحيات، متابعة أداء السيرفرات والأمان، وإعدادات الذكاء الاصطناعي.

## 🤖 تقنيات الذكاء الاصطناعي التفاعلية (AI Capabilities)

- **AI Itinerary Planner**: توليد خطة سياحية يومية متكاملة بناءً على الميزانية، الاهتمامات، ونوع الرحلة.
- **AI Tourist Assistant**: مساعد سياحي ذكي متاح 24/7 للإجابة عن الاستفسارات واستكشاف الفعاليات القريبة.
- **AI Smart Tour Guide**: مرشد تفاعلي يعرض حقائق تاريخية وثقافية لكل معلم بالصوت والنص.
- **Augmented Reality & 3D View**: معاينة المعالم البارزة بتقنية 3D والواقع المعزز قبل الزيارة.
- **Smart Translation**: ترجمة فورية متعددة اللغات مخصصة للمصطلحات السياحية والتراثية السعودية.

## 🚘 أسطول التنقل الذكي (Explorer Ride)

- حجز مركبات كهربائية وذاتية القيادة فاخرة للتنقل بين المدن والمعالم.
- تتبع حي للرحلات بالخريطة التفاعلية.
- تفعيل وضع المرشد الصوتي أثناء الرحلة (AI Tour Mode) لسرد قصص المناطق التي تمر بها السيارة.
- إصدار الفواتير الرقمية الفورية وتقييم السائقين.

## 🛠️ البنية التقنية (Tech Stack & Architecture)

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS.
- **Icons & Motion**: Lucide React, Motion (Framer Motion).
- **Visualization**: Recharts, D3.js.
- **Routing & State**: Internal Reactive View Manager with Context & State Hooks.
- **Accessibility**: High Contrast Mode, Dynamic Typography Scaling, Screen Reader Friendly, RTL Support.
- **SEO & Meta**: Complete Schema.org Structured Data, Open Graph, Sitemap XML, Robots.txt.

## 🚀 دليل البناء والنشر (Build & Deployment)

### التشغيل المحلي (Development):
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev
```

### البناء للإنتاج (Production Build):
```bash
npm run build
```

### النشر على السحابة (Hosting Setup):
- **Vercel / Netlify**: ربط المجلد الرئيسي وتحديد أمر البناء `npm run build` ومجلد الخرج `dist`.
- **Firebase Hosting**: استخدام `firebase deploy` مع ضبط المجلد المباشر إلى `dist`.
- **Cloudflare Pages**: اختيار إطار العمل Vite والمسار `/dist`.
